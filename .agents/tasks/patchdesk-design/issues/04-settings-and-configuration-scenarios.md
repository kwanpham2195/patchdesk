# 04 — Settings and configuration scenarios

**What to build:** A designer can review Settings with realistic profile, appearance, diff-theme, watchlist, environment, storage, and confirmation states, and can make local edits that reset on reload.

**Blocked by:** 01 — Design app foundation and default inbox

**Status:** ready-for-agent

- [ ] Settings opens as a stable Design scenario with realistic profile and workspace data.
- [ ] Light, dark, and system appearance choices can be reviewed locally.
- [ ] Diff-theme selection renders through the same preference behavior as Patchdesk.
- [ ] Watchlist discovery, repository path, archive, removal, GitHub access, environment, and storage surfaces render representative states.
- [ ] Settings actions return deterministic success and failure feedback without touching local files or remote services.
- [ ] Confirmation dialogs are reachable and cancelable.
- [ ] Reloading resets all mock settings and edits to the curated baseline.
