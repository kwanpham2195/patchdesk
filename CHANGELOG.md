## 0.0.10 - 2026-09-22

- Preserved inline pending-review drafts after GitHub safely rejects them. The failed card now shows the complete message and offers **Edit draft**, which restores the body and valid anchor into the canonical composer; if Refresh invalidated the anchor, Patchdesk keeps the text until another diff line is selected. Outcome-unknown writes remain locked for reconciliation and cannot be retried from the card. #339

- Fixed Insight runs reporting a missing or mismatched Review worktree as a provider-runtime failure. The failed Insight now explains that the Review's local files are unavailable and offers **Re-prepare Review**, which rebuilds the same represented revision through the durable refresh lifecycle before another run. Failed command traces also keep long commands on one truncated row while preserving their duration and full text on hover. #245 #261

- Fixed Refresh GitHub state losing ownership when GitHub preparation exceeded the desktop request timeout. Refresh now persists its operation and prepared Review before adoption, keeps visible progress while it runs, resumes the same operation after a renderer reload, and reports an interrupted or failed operation without replacing the readable Review. #264
- Fixed closing the Insight run dialog while Codex models were loading reporting the Codex runtime as unavailable. A cancelled load is now discarded by the dialog that owned it, and reopening can load models again while genuine runtime failures remain visible. #256

- Fixed an Insight status poll scheduling another browser timer after its Review or renderer had already been disposed. Late poll responses now stop before touching the renderer timer, preventing intermittent `window is not defined` failures in the full test gate. #252
- Fixed numeric-looking assignee and maintainer search text being inferred as GraphQL numbers. Free-text searches such as `2026` now remain strings while numeric pagination variables retain their existing types. #279
- Clarified that a Context-unavailable GitHub read affects unchanged-context expansion, while the saved patch remains visible. #275
- Prevented new watches for merged or closed pull requests. Their inspector no longer offers Watch, and a palette attempt reports the terminal state without saving it. #269
- Kept readable watched pull requests updating when another watch is inaccessible, while retaining the inaccessible watch for a later poll. #268

- Improved how long every exchange with GitHub takes. Patchdesk now talks to GitHub directly for every read and every write — checks, permissions, branch rules, conversation comments, the pull request itself, its diff, its reviews and review comments, its inline review threads, its merge readiness, its commits, its labels and reviewers, the people it can be assigned to, the branches you can move it onto, the Pull requests search, and every comment, thread, review, label, assignee, reviewer, draft change, base branch change, and merge you make — rather than through the GitHub CLI, which saves a process launch and a fresh connection on each one.
