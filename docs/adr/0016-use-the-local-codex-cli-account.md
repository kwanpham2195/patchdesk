# Use the local Codex CLI account

Patchdesk supports a **Codex CLI account provider** alongside Pi for Analysis runs and Walkthroughs; the maintainer selects the provider, model, and reasoning level in each run dialog, which repeats the choice before confirmation, preserves separate non-secret preferences per insight type, and records frozen resolved provider/model provenance for the run. Codex is discovered only through inherited PATH and starts only after an explicit user action; each run uses a fresh app-server process and thread plus an immutable prepared-artifact directory, revalidates its live `model/list` choice, never resumes a thread or starts/embeds login, automatically denies tool and permission requests, and reports only structured failures with bounded redacted local diagnostics. Codex results must satisfy the existing strict contracts and authority boundaries, may run concurrently under ADR-0012, and require deterministic fake-app-server coverage; live-account verification is optional and user-initiated.
