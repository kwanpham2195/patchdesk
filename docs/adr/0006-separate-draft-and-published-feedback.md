# Separate draft and published feedback

Patchdesk keeps unpublished Review draft content separate from feedback that GitHub has accepted. After a successful publication, the submitted content leaves the active draft and remains visible as Published feedback. The workbench starts a new empty draft for later commits or discussion.

Published feedback follows GitHub's capabilities. Patchdesk may let the author edit or delete an individual review comment when GitHub permits it, while submitted review decisions remain separate GitHub review records that may require dismissal rather than deletion. Patchdesk never represents published content as an editable local draft.
