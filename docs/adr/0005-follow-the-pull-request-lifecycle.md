# Follow the pull request lifecycle

A Patchdesk review remains active while its GitHub pull request is open. Publishing a GitHub review and completing an analysis are milestones within that review; neither completes it. This lets the same review continue when the author pushes commits or replies to feedback.

Merging or closing the pull request makes the review terminal. The final workbench remains inspectable with its merged or closed status, but no longer offers actions that GitHub cannot accept. Removing local review data remains a separate cleanup action.
