## Why this matters

React Doctor 0.9.11 completed a full scan but scored Patchdesk 34/100 from 44 errors and 215 warnings across 96 files. That score is not yet a trustworthy application-health signal: 32 of the 44 errors came from generated output, Node scripts, or the separately packaged Flue runtime. The first remediation step is to keep real source findings while excluding outputs and rules that are invalid for a given runtime. Do not change production behavior to satisfy a mis-scoped scan.

## Current state

- `package.json:7-28` defines all quality commands. `doctor` currently runs `npx react-doctor@latest` even though `react-doctor` is a local dev dependency pinned by the lockfile. This can change rule behavior without a dependency update.
- The full scan at commit `a3813b8` was complete: 342 files, no skipped checks, schema version 3, score 34, 44 errors, and 215 warnings.
- `out/**` and `release/**` are ignored generated outputs. The two `artifact-env-leak` errors contained provider credential names only. `out/workflow-runtime/package-smoke-runner.js` was enforcing that provider credentials were absent.
- Twenty-nine `eslint/no-undef` errors were Node globals in `scripts/**/*.mjs` and `runtime/flue/scripts/**/*.mjs`. Oxlint is the repository lint authority and already applies Node environment policy to scripts.
- `runtime/flue/` is a separate exact runtime with its own package, tests, and capability contract. Root React Doctor incorrectly treated Flue's `useTool` registration as a React Hook loop.
- React Doctor 0.9.11 accepts `ignore.files` and per-file `ignore.overrides[].rules` in `doctor.config.*`. Use those controls instead of inline source suppressions.

## Steps

### Step 1: Capture a reproducible baseline

Run the local binary, write JSON to a fresh temporary directory, and verify `schemaVersion === 3`, `ok === true`, every selected project is complete, and `skippedChecks` is empty. Save only the counts and command in the commit/PR description; do not commit generated scan output.

**Verify**:

```bash
RUN_DIR="$(mktemp -d "${TMPDIR:-/tmp}/react-doctor.XXXXXX")"
pnpm exec react-doctor . --json --blocking none --yes --scope full --no-cache --json-out "$RUN_DIR/before.json"
jq -e '.schemaVersion == 3 and .ok == true and all(.projects[]; .complete == true and (.skippedChecks | length) == 0)' "$RUN_DIR/before.json"
```

Expected: `true` and exit 0.

### Step 2: Add narrow runtime and artifact exclusions

Create `doctor.config.json` with the schema URL generated by React Doctor's own `rules` tooling. Configure:

- `ignore.files`: ignored generated outputs (`out/**`, `release/**`, `test-results/**`) and the separate `runtime/flue/**` package.
- One `ignore.overrides` entry for `scripts/**/*.mjs` that ignores only `eslint/no-undef`; do not ignore other server, security, or performance rules for scripts.
- Do not disable `react-doctor/no-ref-current-in-render`, effect ownership, list identity, accessibility, or async rules.

If React Doctor's generated schema/config format differs, use the locally installed 0.9.11 format and document the difference. Do not guess unsupported fields.

**Verify**: `pnpm exec react-doctor rules list --configured --json | jq .` exits 0 and config loading prints no warnings.

### Step 3: Pin the repository command to the installed binary

Change `package.json#scripts.doctor` from `npx react-doctor@latest` to `react-doctor --scope full`. The lockfile remains the version authority. Keep ad hoc scopes possible through `pnpm run doctor --scope changed --base <ref>`.

**Verify**: `pnpm run doctor --score` prints a numeric score and uses the local version reported by `pnpm exec react-doctor --version`.

### Step 4: Prove scan coverage improved without hiding app findings

Run the same JSON scan again. Assert:

- no diagnostic path starts with `out/`, `release/`, `test-results/`, or `runtime/flue/`;
- no `eslint/no-undef` diagnostic comes from `scripts/**/*.mjs`;
- all renderer files with the original 11 `no-ref-current-in-render` findings are still analyzed and those findings remain until Plan 011;
- the scan is complete with no skipped checks.

**Verify**:

```bash
pnpm exec react-doctor . --json --blocking none --yes --scope full --no-cache --json-out "$RUN_DIR/after.json"
jq -e '[.projects[].diagnostics[].normalizedFilePath] | all(.[]; (startswith("out/") or startswith("release/") or startswith("test-results/") or startswith("runtime/flue/")) | not)' "$RUN_DIR/after.json"
jq -e '[.projects[].diagnostics[] | select(.rule == "no-ref-current-in-render")] | length > 0' "$RUN_DIR/after.json"
```

Expected: both expressions are `true`.

### Step 5: Run repository checks

Run `pnpm format:check`, `pnpm lint`, `pnpm typecheck`, and `git diff --check`.
